# ColumnFit Privacy Policy

Last updated: September 06, 2026

## Summary

ColumnFit does not retain copies of your spreadsheet content or send it to its developer. All spreadsheet processing happens on Google’s infrastructure through Google Apps Script™.

## What the Add-on accesses

ColumnFit requests one Google permission: view and manage spreadsheets that this application has been installed in (`https://www.googleapis.com/auth/spreadsheets.currentonly`). It uses this to read cell text, font sizes, wrap settings, and column widths in the active sheet, and to set row heights. This permission does not grant general access to other files in your Google Drive™.

## What we collect

The Add-on has no developer-operated servers, no analytics, no external API calls, and no persistent storage. It does not log spreadsheet content or send it to us.

If you contact support, we receive your email address and any information you include so we can respond to your request. Support messages are handled through Google Groups™. Access within the support group is restricted to ColumnFit’s developer; messages are not public.

## Third parties

Google provides the infrastructure for the Add-on and support messages. The Add-on does not send spreadsheet data to other third-party services.

The website is hosted on GitHub Pages, which logs visitors’ IP addresses for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Google API Services User Data Policy

ColumnFit's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

The Add-on does not retain separate copies of spreadsheet content. Row-height changes remain saved in your spreadsheet.

You can uninstall the Add-on and revoke its access through your [account’s app-access settings](https://myaccount.google.com/connections). Removing access does not reverse changes already saved in your spreadsheet.

Support messages may remain stored until manually deleted. Contact us to request deletion of your support correspondence.

## Changes

We will update this page if the Add-on’s data practices change. Before using Google user data for a previously undisclosed purpose, we will notify users and obtain consent.
