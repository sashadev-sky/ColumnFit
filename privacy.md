# ColumnFit Privacy Policy

Last updated: September 03, 2026

## Summary

ColumnFit does not collect, store, or transmit your data. All processing happens inside Google Apps Script within your Google account.

## What the Add-on accesses

ColumnFit requests one Google permission: view and manage spreadsheets that this application has been installed in (`https://www.googleapis.com/auth/spreadsheets.currentonly`). It uses this to read cell text, font sizes, wrap settings, and column widths in the active sheet, and to set row heights. It cannot see other spreadsheets in your Drive.

## What we collect

Nothing. The Add-on has no servers, no analytics, no external API calls, and no persistent storage. No spreadsheet content, account information, or usage data leaves Google's infrastructure or reaches us.

## Third parties

None. The Add-on does not share data with any third party.

## Google API Services User Data Policy

ColumnFit's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

Because nothing is collected, there is nothing to retain or delete. Uninstalling the Add-on removes its access to your spreadsheets.

## Changes

We will update this page if the Add-on's data practices change.
