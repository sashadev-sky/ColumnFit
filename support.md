# ColumnFit Support

## How to use

### Fit rows to selected columns

1. Select one or more columns (Ctrl-click / Cmd-click for non-adjacent columns).
2. Open Extensions → ColumnFit → Fit rows to selected columns.
3. Rows resize to fit the wrapped text of the selected columns only.

## Requirements

The selected columns must use Wrap text formatting in Google Sheets™. Change Clip or Overflow to Wrap before running ColumnFit.

## Common questions

**Rows are slightly too short or too tall.**
Heights are estimated from font metrics and column widths. Re-run after adjusting column width.

**Rows stopped auto-growing when I edit.**
ColumnFit sets fixed row heights. Edit your content, then run it again.

**Which columns count?**
Only the selected ones. Other columns keep their content but do not influence the calculated row height.

**Can I undo?**
Yes. Use Ctrl+Z / Cmd+Z to undo the row-height changes.
